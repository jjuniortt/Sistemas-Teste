# Data Weaver

Aja como um analista de requisitos e desenvolvedor de sistemas.

Crie um sistema de cadastro, contendo login de acesso, dados estáticos e com base nas informações contidas no documento PDF em anexo.

Objetivo:

- Identificar, organizar e transformar os dados do PDF em uma estrutura de cadastro clara e funcional.

Tarefas:

1. Ler e interpretar o conteúdo do PDF.

2. Extrair todas as informações relevantes para cadastro.

3. Organizar os campos em categorias lógicas.

4. Propor a estrutura do sistema de cadastro.

5. Sugerir validações, regras de preenchimento e possíveis dependências entre campos.

6. Identificar eventuais lacunas ou ambiguidades no documento e listar dúvidas necessárias para completar o sistema.



Formato da resposta:

- Visão geral do sistema

- Campos do cadastro

- Categorias/seções

- Regras de validação

- Campos obrigatórios e opcionais

- Dúvidas e inconsistências identificadas

- Sugestão de implementação, se aplicável

Critérios de qualidade:

- Manter fidelidade ao conteúdo do PDF

- Não inventar informações que não estejam no documento

- Ser claro, objetivo e estruturado

- Priorizar usabilidade e organização dos dados

Se houver mais de uma interpretação possível para algum dado do PDF, destaque isso explicitamente.
